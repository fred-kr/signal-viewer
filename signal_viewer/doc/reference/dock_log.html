Status Log dock

A running log of what the application did: files opened, channels loaded, settings changed, peaks found, and every warning or error. Hidden by default; open it from the View or Help menu. It docks at the bottom of the window and can be floated.

Each line reads time | level | message. Levels are DEBUG, INFO, SUCCESS, WARNING, ERROR and CRITICAL. Right-click the log for Clear Log.

Warnings and errors

Every message of level WARNING or higher also pops up as a message box, so you never need the log open to be told about a problem. The box shows the message; Show Details adds the full text and, for errors raised by the code, the traceback that helps when reporting a bug. Typical warnings:

  • Select a peak detection method first. Ctrl+F was pressed without a method.
  • The currently selected peak detection method finds less than 2 peaks. Change parameters or method.
  • Need at least 3 detected peaks to create a result. A section with too few peaks was locked.
  • Nothing to export. No section exists yet.

Debug log file

Started with --debug, the application additionally writes every message, including DEBUG level, to debug.log in the per-user application data folder; see Command line flags for the location. Attach that file when reporting a problem.
