Main window, menus and shortcuts

The main window has three pages in tabs along the top: Import, Graph and Results. Three dock windows can be attached to its sides: Sections and Parameter Inputs, which appear on the Graph page, and the Status Log, hidden by default. Docks can be dragged to another side, floated or closed; the View menu brings them back. The window remembers its size and the dock layout between runs.

While a background task runs (peak detection, computing a section result) a translucent overlay covers the window and blocks input until the task finishes.

Toolbars

  • Main toolbar: Open File..., Preferences, and the Channel drop-down that switches the channel being edited (see Channels).
  • Help toolbar: What's This? and User Guide.
  • The Sections dock has its own command bar with the section actions.

Where help appears

  • Tooltips appear when the mouse rests on a control. In the Parameter Inputs dock they state meaning, unit, default and range of an input; the drop-down entries have tooltips too.
  • What's This (Shift+F1, then click) shows a longer explanation. Most of them end with a link that opens the matching page of this guide.
  • F1 opens this guide at the page for the Import, Graph or Results page, or at the Parameter Inputs reference when the dock has keyboard focus.
  • Warnings and errors pop up as message boxes and are kept in the Status Log.
