File Metadata dialog

Opened by File > File Metadata, and automatically after opening a file whose sampling rate or signal channel could not be determined. It edits the same three values as the form on the Import page; both views always show the same state.

Required Metadata tab

FieldContent
File NameRead-only.
File TypeRead-only. The extension, which selects the reader (see File formats).
Sampling Rate*Samples per second. <Not set> while unknown. Required.
Signal Channel*The numeric column to analyse first. Required.
Info ChannelOptional column summarised per rate window. <No Selection> for none.

While a required field is missing, a line in the form says which (Missing: Sampling rate) and Save is disabled. Save applies the values to the open file; Cancel discards the edits. After the data is loaded the values are fixed; close and reopen the file to change them.

Additional Metadata tab

Metadata stored in the file itself, as a read-only, searchable tree. For EDF files this is the header information read by the mne library (channel names, recording date, measurement units, ...). Tabular files have no additional metadata.
