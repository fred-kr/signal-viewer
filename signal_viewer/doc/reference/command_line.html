Command line flags

The packaged executable (SignalViewer.exe, SignalViewer.app) and the source command uv run sv accept the same flags. The README of the project is the primary place for this list.

FlagEffect
--debugVerbose logging to the terminal and to debug.log in the per-user application data folder: Windows %LOCALAPPDATA%\QuackTech\SignalViewer - Debug, macOS ~/Library/Application Support/QuackTech/SignalViewer - Debug. Settings are kept separately from a normal run.
--no-openglDisable OpenGL rendering of the plots. Try this if plots stay blank.
--reset-settingsDelete the stored settings and start with defaults.
--versionPrint the version and exit.
--self-testBuild the whole user interface off-screen and exit. Used to smoke-test packaged builds.
-c, --consoleDeveloper option: adds a Jupyter console to the View menu with the application objects in its namespace. Needs the development dependencies.
