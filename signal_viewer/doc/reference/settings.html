Settings

Settings > Preferences (Ctrl+,) opens the Settings dialog. Each setting has a reset button that restores its default. OK applies the changes, Cancel restores the values from before the dialog opened. Settings are stored per user and survive restarts; the --reset-settings command line flag deletes them.

Plot

SettingDefaultMeaning
Line click width70 pxThe width in pixels orthogonal to the signal curve that responds to a mouse click. Larger values make the curve easier to hit when adding peaks.
Click radius20 pxThe radius in pixels around a click that is searched for an extreme point when adding a peak by hand.

Processing

SettingDefaultMeaning
Filter stackingoffWhether a filter may be applied to an already filtered signal. In this version Apply to Signal always starts from the raw signal, so the setting has no visible effect.
Rate computation methodRollingWindowHow the rate is derived from the peaks: RollingWindow counts peaks in a moving window (settings on the Rate Calculation tab), Instantaneous interpolates one value per sample from the peak intervals. Changing it recomputes the rate of every unlocked section; locked sections keep their result.

Data

SettingDefaultMeaning
Float precision3Number of decimal places shown in the tables. Exported files hold the full values. Changing it refreshes the tables.
Text file separatorTabCharacter between the fields of a .txt file: Tab, Space, Comma, Semicolon or Pipe. .csv files always use the comma and .tsv files the tab. Takes effect on the next file opened.

The application also stores the last used folders, the last chosen sampling rate and channels (pre-selected when the next file has the same column), the recent-files list and the window layout. These have no entry in the dialog.
