Parameter Inputs dock

Every input of the dock, with its unit, default value and range. The dock is shown on the Graph page and is enabled for unlocked, user-created sections only. The same texts appear as tooltips in the dock; a default marked "at load" is replaced when a file is loaded. How-to: Preprocessing, Peak detection, Rate calculation.

Preprocessing tab

Command bar and status

ControlWhat it does
Apply to SignalApplies the selected processing steps to the raw signal of the active section. Earlier processing and all peaks are discarded first.
Restore DefaultsRestores the default values of the pipeline, filter and standardization inputs. Does not touch the signal.
Reset SignalRestores the raw signal of the active section. Every processing step and every peak is removed.
Check mark next to PipelineChecked while the signal of the active section was cleaned with a pipeline.
Check mark next to Filter MethodChecked while the signal is filtered. Its tooltip counts the filters applied in turn.
Check mark next to Standardization MethodChecked while the signal is standardized.

Peak Detection tab

Command bar

ControlWhat it does
Run detectionRuns the selected method on the processed signal of the active section, in the background. Existing peaks, including manual edits, are replaced.
Restore DefaultsRestores the default parameter values of the selected method.
Reset PeaksRemoves every peak of the active section. The processed signal is kept.

Rate Calculation tab

InputUnitDefaultRangeMeaning
Incomplete window handling methodDropDrop, Approximate, RepeatLastWhat to do with windows at the end of a section that are shorter than the window length: leave them out, scale their peak count up to a full window, or repeat the rate of the last complete window.
New window everys101 to 600Time between the starts of consecutive rate windows. Sets how many rate rows a section produces.
Window Lengths601 to 10000Length of each rate window. The peaks inside are counted and scaled to beats per minute. Longer windows give a smoother rate.

The rate inputs apply to every section at once; the active section's rate is recomputed immediately. Whether the rolling window is used at all is the Rate computation method setting.
