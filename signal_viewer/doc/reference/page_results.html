Results page

Shows the result of the active section (once it is locked) and exports the results of all sections. How-to: Results and export.

ControlWhat it does
Section labelNext to the page title: the section whose results are shown (the active section).
Save to ExcelExports every section of every loaded channel to one or more workbooks. Same as Export to XLSX in the table context menus.
Plot View tabThe result figure. Show chooses the active section or all locked sections; Fit the model drawn into the rate-versus-info panel (Exponential, Linear, Smooth, None); k the knot count of the Smooth model (Auto = from the data). Details: Result plot.
Peak Indices tabOne row per peak: section index, processed signal value, file index, info value. Right-click to copy or export.
Calculated Rate / Summary Statistics tabOne row per rate window: peaks and rows in the window, info channel statistics, rate in bpm. Right-click to copy or export.
Metadata tabDisabled in this version. The processing parameters of a section are shown by Show Section Summary in the Sections dock and written into the section summary.

Table context menu

EntryEffect
Copy to ClipboardCopies the whole table as tab-separated text, ready to paste into a spreadsheet.
Export to CSVWrites the shown table of the active section to a CSV file. Default name Result_<Channel>_<file>.csv.
Export to XLSXWrites every section of every channel; see Export to Excel.

The tables display floats with the number of decimals set in Settings > Data > Float precision; exported files hold the full values.
