Import page

The first page of the main window: open a file, complete its metadata, load a channel. How-to: Getting started.

ControlWhat it does
Open File...Opens a file dialog filtered to the supported formats. Scans the file for columns and sampling rate; loads nothing yet.
File name fieldRead-only. The name of the open file; also shown in the window title.
Sampling RateSamples per second (Hz). Detected from a time column or the EDF header when possible; 0 Hz means unknown and must be entered. Required.
Signal ChannelThe numeric column to analyse first. Required.
Info ChannelOptional numeric column summarised per rate window (temperature, oxygen saturation, ...). <No Selection> for none.
Status lineBelow the form. Lists the required fields that are still missing, e.g. Missing: Sampling rate. Empty when loading is possible.
Close FileCtrl+R. Discards every channel, section and result.
Load DataReads the signal and info channel, creates the base section and switches to the Graph page. Disabled while a required field is missing.
Recent Data FilesThe last ten files opened, newest first. Double-click to open one. Missing files are removed from the list.
Data tableThe frame of the active section after loading: index, section_index, raw signal, processed signal, is_peak, is_manual, info channel. The label above names the section. Hover a header for the data type, a cell for the exact value.

Sampling rate and channels can be changed until the data is loaded; afterwards the three fields are disabled. Change them in the File Metadata dialog before loading, or close and reopen the file.
