Requirements for tabular files

  • One row per sample, one column per channel, column names in the first row.
  • Only numeric columns can be the signal or info channel. A column with a stray non-numeric value in its first 10000 rows is read as text and does not appear in the lists.
  • The column names index, section_index, is_peak and is_manual are reserved.

Sampling rate detection

A time column is looked for among: columns whose name contains time or ts, date-time and duration columns, and integer columns whose name does not contain index. When exactly one candidate exists, the sampling rate is the number of rows whose time lies within the first second. Floats are read as seconds, integers as microseconds, date-times as such. With no candidate or several, the rate stays unknown and has to be entered.
