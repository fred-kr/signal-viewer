SignalViewer User Guide

SignalViewer finds the peaks (heartbeats) in a recorded physiological signal such as an ECG or a photoplethysmogram (PPG), lets you correct them by hand, and turns them into a rate per time window. It is made for lab work where a long recording is cut into sections of interest, each section is cleaned and checked, and the rates of all sections are exported to one Excel workbook for analysis elsewhere.

The workflow

  1. Open a file and load a channel. Set the sampling rate and pick the signal column; optionally pick an info column such as temperature.
  2. Create a section covering the stretch of the recording you want to analyse. The whole file is the base section; sections are slices of it.
  3. Preprocess the signal of the section with a ready-made pipeline or your own filter.
  4. Detect the peaks with one of the detection methods and fix single peaks by clicking on the plot.
  5. Lock the section and export the results. Locking computes the rate per window; the export writes every locked section of every channel.

Help inside the application

  • F1 opens this guide at the page for what you are looking at: the Import, Graph or Results page, or the Parameter Inputs dock when it has the keyboard focus.
  • Shift+F1 (or the question mark button in the toolbar) enters What's This mode. Click any button, field or menu entry to read what it does; most of these texts end with a link into this guide.
  • Hovering an input in the Parameter Inputs dock shows a tooltip with the meaning, unit, default and range of the value. The entries of every drop-down list have tooltips describing the method they stand for.
