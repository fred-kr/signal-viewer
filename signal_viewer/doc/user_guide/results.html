Results and export

A section has a result once it is locked: a table of its peaks and a table of its rate per window, both computed from the final peaks. The Results page shows the result of the active section as a plot and as tables, and the export writes the results of every locked section of every channel to Excel.

Rate calculation

The rate is derived from the peaks in one of two ways, chosen in Settings > Processing > Rate computation method:

  • Rolling window (default): a window of fixed length moves along the section in fixed steps; the peaks in each window are counted and scaled to beats per minute. One rate value per window.
  • Instantaneous: one rate value per sample, interpolated from the time between consecutive peaks. Follows every beat, and every missed beat.

The Rate Calculation tab of the Parameter Inputs dock sets the rolling window:

  • Window Length: the length of each window in seconds (default 60 s). Longer windows give a smoother rate.
  • New window every: the step between window starts in seconds (default 10 s). It determines how many rate rows a section produces.
  • Incomplete window handling: what to do with the windows at the end of the section that are shorter than the window length. Drop leaves them out, Approximate scales their peak count up to a full window, RepeatLast repeats the rate of the last complete window.

These settings apply to every section, and changing them recomputes the rate of the active section at once (the lower plot on the Graph page shows it). Locked sections keep the result they were locked with.

Result tables

Peak Indices has one row per peak: section_index (row within the section), the processed signal value, global_index (row within the file) and the value of the info channel at the peak.

Calculated Rate / Summary Statistics has one row per rate window: section_index of the window start, peaks_in_window, rows_in_window, the mean, standard deviation, minimum, maximum and variance of the info channel within the window (columns named after the info channel, e.g. temperature_mean), and rate_bpm.

Right-click either table to Copy to Clipboard (tab-separated, pastes into a spreadsheet), Export to CSV (the shown table only) or Export to XLSX (all sections, see below). Floats are shown with the number of decimals set in Settings > Data; the exported files hold the full values.

Result plot

Plot View draws, from top to bottom, the rate over time, the info channel over time (when the section has one) and the interval between consecutive peaks over time. With an info channel, a fourth panel on the right plots every rate window against the mean of the info channel in that window, with the mean rate per 0.1 step of the info value drawn as a line.

  • Show switches between the active section (time since section start) and all locked sections of the channel on the file's time axis, with alternating bands and the section numbers marking the sections.
  • Fit fits a model to the rate-versus-info points and writes its equation into the panel title. Exponential (a Gamma GLM with log link, rate = exp(a + b x)) is the usual shape of a rate-temperature relation; when the info channel is a temperature the title also shows Q10, the factor by which the rate changes per 10 degrees. Linear is ordinary least squares. Smooth is a penalized spline whose smoothness is chosen by cross-validation; k sets its number of knots, Auto derives it from the number of points. None draws no model.

The figure is only drawn while the Plot View tab is visible, so switching settings on other tabs costs nothing. A fit that is not possible (too few points, no spread in the info values) is reported in the status log and skipped.

Export to Excel

Save to Excel on the Results page (also Export to XLSX in the table context menu) writes every section of every loaded channel. The steps:

  1. If any section is not locked, a warning lists them; their rows will be missing or incomplete. Lock them first or continue.
  2. With sections on more than one channel you choose One file (all channels in one workbook, with a channel column on every sheet) or One file per channel.
  3. You may enter a label for a group_var column, e.g. an animal id or condition, which makes it easy to combine the files of several recordings in R or Python. Leave it empty to add no label.
  4. Pick the file name, or the folder for the per-channel files. Per-channel files are named Result_<Channel>_<file>.xlsx and existing ones are only replaced after confirmation.

Every workbook has four sheets:

SheetRowsColumns
r_dataOne per rate window of every sectionchannel, section_id, index (file row of the window start), the info mean, rate_bpm, group_var. Made for statistics software.
Detected PeaksOne per peakchannel, section_id, the Peak Indices table.
Rate DataOne per rate windowchannel, section_id, the Calculated Rate table.
Global BoundsOne per sectionchannel, section_id, global_start, global_end: the first and last file row of the section.

section_id is the position of the section within its channel, starting at 1. A dialog confirms the written paths; the folder is remembered for the next export.
