Getting started

This page takes a recording from a file on disk to the Graph page, where sections are made and peaks are detected. Everything happens on the Import page, the first tab of the main window. For installing the application see the README that comes with it.

Open a file

Press Open File... (also in the File menu and the toolbar) and choose a file. SignalViewer reads text files (.csv, .txt, .tsv), Excel workbooks (.xls, .xlsx), Apache Arrow files (.feather, .arrow, .ipc) and EDF recordings (.edf). Text and Excel files need one column per channel with the column names in the first row. Details are in File formats.

Opening does not load the data yet. The file is scanned for its column names and types and, where possible, for its sampling rate. The result fills the Required Information form; the data table on the right stays empty until you press Load Data.

Files you opened before are listed under Recent Data Files. Double-click an entry to open it again. Entries whose file no longer exists disappear from the list.

Sampling rate

The sampling rate is the number of samples recorded per second (Hz). It turns sample numbers into time, and every filter and detection method depends on it, so the application refuses to load data without it.

SignalViewer fills it in by itself when it can:

  • EDF files carry the sampling rate in their header.
  • Tabular files are searched for a time column: a column whose name contains time or ts, a date-time or duration column, or an integer column whose name does not contain index. The sampling rate is the number of rows in the first second of that column. Floats are read as seconds, integers as microseconds.

When no single time column is found, the field shows 0 Hz and the status line below the form says Missing: Sampling rate. Type the rate of your recording into the field.

Signal channel and info channel

Signal Channel is the column holding the signal to analyse. Only numeric columns are offered; the first one is pre-selected, or the column you chose the last time if the file has it too. This channel is loaded first. Every other numeric column can be analysed afterwards through the channel switcher on the Graph page, without reopening the file (see Channels).

Info Channel is an optional second column recorded alongside the signal, typically a temperature or an oxygen saturation. Choose <No Selection> when there is none. When one is chosen:

  • the rate table gets the mean, standard deviation, minimum, maximum and variance of the info channel per rate window,
  • the result plot shows the rate against the info channel and fits a model to it,
  • the Excel export includes the info mean per window.

Column names are cleaned for use inside the application: lower case, special characters and spaces replaced by underscores, accents removed. Tables and exported files show the cleaned names; the drop-down lists show the names as they are in the file. The names index, section_index, is_peak and is_manual are reserved and cannot be chosen.

Load the data

Press Load Data. The button is disabled while a required field is missing; the status line under the form names the field. Loading reads the signal channel and the info channel from the file and switches to the Graph page, where the whole recording appears as the base section, named Section 000 followed by the channel name. From here, continue with Working with sections.

The data table on the Import page now shows the frame of the active section: index (row in the file), section_index (row in the section), the raw signal, its processed copy, is_peak, is_manual and the info channel. Hover a header to see the data type, a cell to see its exact value.

Loading the same file again (after changing the sampling rate or the channels, which is possible until the first load) discards all sections of the earlier load.

The File Metadata dialog

File > File Metadata opens a dialog with the same three values and, on its second tab, the metadata stored in the file itself: for EDF files the header information read by the mne library. The dialog also opens by itself right after opening a file that lacks a sampling rate or a usable signal column. Reference: File Metadata dialog.

Close the file

Close File (button on the Import page, or File menu) discards every channel, section and result and returns the application to its start state. Export your results first; see Export to Excel. Opening another file closes the current one in the same way.
