Working with sections

A section is a contiguous stretch of one channel. All processing, peak detection and rate calculation happens per section, and every section is exported on its own rows. The whole channel is the base section, Section 000; the sections you create are slices of it and are numbered 001, 002, ... in the order of creation. The base section itself is locked: to process or detect anything, create a section first.

Sections live in the Sections dock on the right of the Graph page, which lists them with a lock icon and holds the command bar for everything below. Reference: Sections dock.

Create a section

  1. Make the base section active (click Section 000 in the list). New Section is only enabled then.
  2. Press New Section. A grey region with two draggable edges appears on the plot. When sections exist already, the region starts right after the last one and has the same length; otherwise it covers the first third of the visible range.
  3. Drag the edges (or the whole region) to the stretch you want. Zoom and pan the plot as needed; the region cannot leave the recording.
  4. Press Confirm in the Sections dock. The new section is added to the list and becomes active. Cancel drops the region instead.

Sections may overlap. Every section gets its own copy of the processing state, peaks and rate, so the same stretch can be analysed twice with different settings.

Switch between sections

Click a section in the list to make it active. The plot, the data table on the Import page, the Parameter Inputs dock and the Results page all show the active section; its name is written above the list and above the result views. With the section overview on (below), clicking a coloured region on the plot activates that section as well.

The Parameter Inputs dock is only enabled for an unlocked, user-created section. For the base section and for locked sections it stays greyed out, and clicks on the plot do not add or remove peaks.

Section overview

Section Overview (command bar or Plot menu) draws every section as a coloured region on the plot of the base section. It is switched on automatically whenever the base section becomes active and is only available there. Hover a region to see the section's name, click it to activate the section.

Lock and unlock a section

When the peaks of a section are correct, press Lock Section. SignalViewer computes the final peak table and the rate per window in the background (the window shows a busy overlay meanwhile) and locks the section: the Parameter Inputs dock is disabled for it, clicks on the plot are ignored, and the lock icon in the list closes. Only locked sections have results on the Results page and in the export.

Locking needs at least three peaks; with fewer an error message explains why nothing happened.

Unlock Section makes a locked section editable again. Its previous result is kept until the next processing step or peak edit, so unlocking and locking again without changes is harmless. Changing the rate computation method does not touch locked sections either: unlock and lock again to recompute them with the new method.

Remove a section

Remove Section (command bar, or right-click the section in the list) deletes the active section with its peaks and results. This cannot be undone. The base section cannot be removed. The sections after the removed one are renumbered, so Section 003 becomes Section 002 when 002 is deleted.

Section summary

Show Section Summary (command bar or context menu) opens a dialog with the section's name, size in samples, sampling rate, first and last row in the file, the number of peaks, and the full processing history: the pipeline or filters applied with their parameters, the standardization, the detection method and its parameters, and the rate computation method. Hovering a section in the list shows a shorter version of the same as a tooltip.

Channels

Every numeric column of the file is a channel. The Channel drop-down in the main toolbar switches the channel being edited. The first switch to a channel reads it from the file; afterwards it stays in memory. Each channel has its own base section and its own list of sections, and switching back shows them exactly as you left them. The channel is part of every section's name, e.g. Section 001 (ECG).

The Excel export writes the sections of every loaded channel, in one workbook or one per channel; see Export to Excel. If the info channel of the file is itself selected as the channel to edit, that channel has no info channel.
