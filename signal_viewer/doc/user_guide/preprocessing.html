Preprocessing the signal

Preprocessing removes drift, noise and mains interference before peaks are detected. You choose it in the Parameter Inputs dock (right side of the Graph page) and it applies to the active section only. The raw signal is never changed: processing writes a processed copy, and Reset Signal brings the raw signal back at any time.

The dock holds the Pipeline dropdown and a command bar. Select a pipeline and press Run: the signal is processed and the peaks are detected in one step. Every input has a tooltip with its meaning, unit, default and range; the complete list is in the Parameter Inputs reference.

Pipelines

A Pipeline is a ready-made cleaning procedure from the neurokit2 library, matched to a signal type and to a detection method. Selecting a pipeline also selects that detection method, so Run needs no further input. You can still choose another method afterwards (Peak Settings).

"One direction" filters introduce a small, constant delay of the processed signal against the raw one. The peak positions are reported on the processed signal.

Custom processing

The first entry of the dropdown, Custom, stands for "no pipeline". It enables the edit button next to the dropdown, which opens the parameters dialog on its Preprocessing tab. There you choose a filter and a standardization yourself; Run then applies those instead of a pipeline. With neither chosen, the detection runs on the raw signal.

While a pipeline is selected the edit button is disabled and the Preprocessing tab is locked. The custom values are kept and come back when you select Custom again. Selecting Custom does not change the detection method.

Custom filter

In the Filter Parameters group, Method chooses one filter of the neurokit2 library and the inputs below hold its settings. Each method uses a different subset of the parameters; the inputs a method does not use are disabled.

MethodUsesNotes
ButterworthLower cutoff, Upper cutoff, OrderZero-phase (forward and backward). The usual choice for a band-pass.
ButterworthLegacyLower cutoff, Upper cutoff, OrderSame filter in transfer-function form; less stable at high orders. For reproducing old results.
ButterworthZILower cutoff, Upper cutoff, OrderOne direction with matched initial conditions: a phase delay, but no edge artefacts.
SavGolOrder, Window SizeSavitzky-Golay smoothing; Order is the polynomial degree.
FIRLower cutoff, Upper cutoff, Window SizeZero-phase FIR band-pass; Window Size is the number of taps. The minimum window size stands for the neurokit2 default.
BesselLower cutoff, Upper cutoff, OrderPreserves peak shapes better than Butterworth at the same order.
PowerlinePowerlineRemoves mains interference at 50 Hz (Europe) or 60 Hz (North America).

A cutoff of 0 means "no cutoff on that side": lower cutoff 0.5 Hz with upper cutoff 0 is a high-pass.

Standardization

In the Standardization Parameters group, Method rescales the filtered signal so that amplitude thresholds of the detection methods behave the same across recordings. It runs after the filter.

  • ZScore subtracts the mean and divides by the standard deviation. With Rolling Window both are computed inside a moving window of Window Size samples, which also removes slow drift; the window should span several beats.
  • ZScoreRobust subtracts the median and divides by the median absolute deviation, so artefacts influence the scaling far less. It cannot be combined with a rolling window.

Run, restore defaults, reset

Run (in the dock, and in the parameters dialog) processes the signal and then detects the peaks. It always starts from the raw signal: earlier processing of the section and all its peaks are discarded first, then the pipeline, or the custom filter followed by the standardization, is applied. The detection follows on the processed signal. Show Section Summary in the Sections dock lists the steps a section has been through.

Restore Defaults in the parameters dialog puts every input of the visible tab back to its default value without touching the signal. Reset Signal in the dock restores the raw signal of the section and removes its peaks.

Processing is not possible on the base section or on a locked section. Detected peaks and manual edits do not survive a new run: settle the pipeline and the detection parameters first, then correct single peaks.
