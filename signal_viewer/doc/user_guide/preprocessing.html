Preprocessing the signal

Preprocessing removes drift, noise and mains interference before peaks are detected. It happens on the Preprocessing tab of the Parameter Inputs dock (right side of the Graph page) and applies to the active section only. The raw signal is never changed: processing writes a processed copy, and Reset Signal brings the raw signal back at any time.

Every input on the tab has a tooltip with its meaning, unit, default and range; the complete list is in the Parameter Inputs reference.

Pipelines

A Pipeline is a ready-made cleaning procedure from the neurokit2 library, matched to a signal type and usually to a detection method. While a pipeline is selected, the custom filter and standardization inputs are disabled. Choose the empty entry to use them instead.

PipelineSignalWhat it applies
PPG_ElgendiPPGButterworth band-pass 0.5 to 8 Hz, order 3. The default; pair with the PPG_Elgendi detector.
ECG_Emrich_2023ECGButterworth high-pass 4 Hz, order 2. Pair with the ECG_Emrich_2023 detector.
ECG_NeuroKitECGButterworth high-pass 0.5 Hz, order 5, then a 50 Hz powerline filter.
ECG_BioSPPyECGFIR band-pass 0.67 to 45 Hz, mean removed.
ECG_PanTompkins_1985ECGButterworth band-pass 5 to 15 Hz, order 1, one direction.
ECG_Hamilton_2002ECGButterworth band-pass 8 to 16 Hz, order 1, one direction.
ECG_Elgendi_2010ECGButterworth band-pass 8 to 20 Hz, order 2, one direction.
ECG_EngzeeMod_2012ECGButterworth band-stop 48 to 52 Hz, order 4, one direction (removes the 50 Hz mains band only).

"One direction" filters introduce a small, constant delay of the processed signal against the raw one. The peak positions are reported on the processed signal.

Custom filter

With no pipeline selected, Filter Method chooses one filter of the neurokit2 library and the Filter Parameters group holds its settings. Each method uses a different subset of the parameters; the inputs a method does not use are disabled.

MethodUsesNotes
ButterworthLower cutoff, Upper cutoff, OrderZero-phase (forward and backward). The usual choice for a band-pass.
ButterworthLegacyLower cutoff, Upper cutoff, OrderSame filter in transfer-function form; less stable at high orders. For reproducing old results.
ButterworthZILower cutoff, Upper cutoff, OrderOne direction with matched initial conditions: a phase delay, but no edge artefacts.
SavGolOrder, Window SizeSavitzky-Golay smoothing; Order is the polynomial degree.
FIRLower cutoff, Upper cutoff, Window SizeZero-phase FIR band-pass; Window Size is the number of taps. The minimum window size stands for the neurokit2 default.
BesselLower cutoff, Upper cutoff, OrderPreserves peak shapes better than Butterworth at the same order.
PowerlinePowerlineRemoves mains interference at 50 Hz (Europe) or 60 Hz (North America).

A cutoff of 0 means "no cutoff on that side": lower cutoff 0.5 Hz with upper cutoff 0 is a high-pass.

Standardization

Standardization Method rescales the filtered signal so that amplitude thresholds of the detection methods behave the same across recordings. It runs after the filter.

  • ZScore subtracts the mean and divides by the standard deviation. With Use rolling window both are computed inside a moving window of Window Size samples, which also removes slow drift; the window should span several beats.
  • ZScoreRobust subtracts the median and divides by the median absolute deviation, so artefacts influence the scaling far less. It cannot be combined with a rolling window.

Apply, restore defaults, reset

Apply to Signal runs the selected steps. It always starts from the raw signal: earlier processing of the section and all its peaks are discarded first, then the pipeline, or the filter followed by the standardization, is applied. The three check marks next to Pipeline, Filter Method and Standardization Method show which steps the active section has been through; hover the filter check mark to see how many filter runs are recorded.

Restore Defaults puts every input of the tab back to its default value (the pipeline PPG_Elgendi, no filter, no standardization) without touching the signal. Reset Signal restores the raw signal of the section and removes its peaks.

Processing is not possible on the base section or on a locked section. Detected peaks and manual edits do not survive a new processing run: process first, then detect and correct.
