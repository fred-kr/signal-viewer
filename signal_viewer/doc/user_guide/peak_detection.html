Detecting and editing peaks

Peak detection runs on the processed signal of the active section from the Peak Detection tab of the Parameter Inputs dock. Detected peaks appear as yellow dots on the signal plot, and the lower plot immediately shows the rate computed from them (see Rate calculation). Afterwards you correct single peaks directly on the plot.

Choose a detection method

Detection Method lists every available algorithm; hover an entry for a description. The inputs under Method Parameters change with the method, and each has a tooltip with its meaning, unit, default and range (full list: Parameter Inputs reference). Methods without a parameter page run with their published defaults.

MethodForHow it works
LocalMaxima, LocalMinimaAny periodic signalA sample is a peak when it is the highest (lowest) value within Radius samples on either side; peaks closer than the radius are merged. The radius defaults to half the sampling rate once a file is loaded. Simple and predictable; a good first try on signals the other methods were not made for.
PPG_ElgendiPPGSystolic peak detector of Elgendi et al. (2013): two moving averages over the squared signal mark the beats. Pair with the PPG_Elgendi pipeline.
ECG_NeuroKitECGThe default ECG detector of neurokit2: QRS complexes are found where the smoothed gradient exceeds a moving threshold, the R-peak is the maximum inside each.
ECG_Emrich_2023ECGFastNVG: visibility-graph detector, fast and sample-accurate. Pair with the ECG_Emrich_2023 pipeline.
ECG_XQRSECGThe XQRS detector of the WFDB package, followed by a correction that moves each location to the real extreme within a radius and removes implausible peaks.
ECG_PromacECGRuns several detectors and keeps the locations most of them agree on. Robust but slow.
ECG_Gamboa_2008ECGHistogram-based amplitude threshold with a gradient search.
ECG_PanTompkins_1985, ECG_Hamilton_2002, ECG_Martinez_2004, ECG_Christov_2004, ECG_Nabian_2018, ECG_EngzeeMod_2012, ECG_Manikandan_2012, ECG_Elgendi_2010, ECG_Kalidas_2017, ECG_Rodrigues_2021ECGClassic and recent R-peak detectors from the literature, as implemented in neurokit2. No parameters.

Run the detection

Press Run detection. The detection runs in the background; a busy overlay covers the window until it finishes. The result replaces every existing peak of the section, including manual edits. If the method finds fewer than two peaks, a warning asks you to change the parameters or the method. Restore Defaults resets the inputs of the shown method page; Reset Peaks removes all peaks but keeps the processed signal.

Detection and processing are tied together: a new processing run discards the peaks. Settle the preprocessing first, then detect, then correct.

Navigate the plot

The upper plot shows the processed signal with the peaks, the lower one the rate; both share the time axis along the top, which shows elapsed time as h:mm:ss and adapts its unit to the zoom level.

  • Mouse wheel zooms the time axis around the cursor. Left-drag pans along the time axis.
  • Right-drag zooms: left/right changes the time scale around the point where the drag started.
  • Scale y-axis (Plot menu) rescales the signal plot to the whole signal again. The y-axis also follows the data automatically while panning.
  • Ctrl+left-drag (or middle-drag) draws a selection rectangle for the commands below.

Edit peaks by hand

Edits only work on an unlocked, user-created section.

  • Add a peak: click on the signal curve near the wanted peak. SignalViewer looks for the local extreme within the click radius (Settings > Plot) around the click and marks it. The curve reacts to clicks within the line click width of it. If no extreme is found, a message in the status log says so.
  • Remove a peak: click on its dot. Dots highlight when hovered.
  • Remove every peak in an area: Ctrl+drag a rectangle over the area, then press Ctrl+D (Plot > Remove Peaks in Selection).
  • Detect inside an area: Ctrl+drag a rectangle, then press Ctrl+F (Plot > Find Peaks in Selection). The currently selected detection method runs on that stretch only and the peaks it finds are added to the existing ones. Ten samples at both edges of the selection are skipped to avoid edge artefacts. Useful for a noisy patch where the global run failed.

Every manual edit is remembered: the exported section frame has an is_manual column with 1 for added and -1 for removed peaks, and the section summary lists the counts. Adding a peak you removed before (or the reverse) cancels the earlier edit.

The rate in the lower plot is recomputed after every edit once the section has more than three peaks.
